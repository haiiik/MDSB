# MDStar 功能一览

这是一份**专门用来做对外截图**的样本：内容自包含、图片是仓库里真实存在的文件，
一屏之内能同时看到标题、正文、表格、代码块与图表。
性能样本（`大图样本文档.md`）里有若干故意不存在的图片占位，会渲染成「图片无法显示」卡片，
**不要拿它做截图素材**。

## 表格

| 模块 | 技术 | 状态 |
| --- | --- | --- |
| 编辑内核 | ProseMirror | 已完成 |
| 源码模式 | CodeMirror 6 | 已完成 |
| 图表 | Mermaid | 已完成 |

## 代码块

```ts
// 按块回写：只有改过的块会被替换，其余逐字节保留
const changed = changedBlocks(sourceDoc, currentDoc);
for (const block of changed) {
  text = patchBlock(text, block);
}
save(text); // 未编辑的文档不会走到这一步
```
